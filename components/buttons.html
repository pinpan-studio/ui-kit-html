Boutons

Boutons Angular Material M3 tels qu'utilisés dans le projet (mat-flat-button primaire majoritaire, mat-raised-button « create-btn » des en-têtes de liste, mat-stroked-button, bouton warn) et classes maison (refresh-btn, action-icon-btn, detail-btn, toggles segmentés).

Variantes

mat-flat-button · mat-stroked-button · mat-button · color="warn"

Correspondance : Primary = mat-flat-button primaire ; Secondary = mat-stroked-button primaire ; Outline = mat-stroked-button neutre ; Ghost = mat-button ; Danger = warn. « Success » est une variante dérivée des jetons --success-color (pas de bouton vert dédié dans l'original).

Toutes les variantes
<button mat-flat-button color="primary">Primary</button>
<button mat-stroked-button color="primary">Secondary</button>
<button mat-stroked-button>Outline</button>
<button mat-button color="primary">Ghost</button>
<button mat-flat-button color="warn">Danger</button>
<button mat-stroked-button color="warn">Danger outline</button>
<button mat-flat-button class="btn-success">Success</button>
